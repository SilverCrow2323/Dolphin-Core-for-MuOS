# Glossary

Terms and acronyms specific to this project.

| Term | Meaning |
|---|---|
| **Burst Link** | Fictional pairing protocol used by Minoru for external controllers. |
| **Chips row** | Row of session-only launch options at the top of the Nexus. |
| **CrossWilson** | Canonical entity in Minoru's lore: a combat profile. |
| **Dual-Face Cel-Tech** | The visual style of DolphinUI (this document set). |
| **Enhancer Dock** | The content store screen (`ethostore.lua`). |
| **Flashback** | Full config backup created before risky operations. |
| **FrontendONE** | The DolphinUI flavour (as opposed to Bash Arsenal or Comfort Zone). |
| **GameSettings** | Per-game INI override, namespaced under `workshop/gamesettings/`. |
| **Homebrew Hub** | Landing page for the `hb/` folder apps. |
| **Live Menu** | In-game overlay opened with MENU+START. |
| **Minoru** | The floating robot companion and character engine. |
| **Minovice** | Canonical entity: Minoru's digital holiday home. |
| **Node5** | Canonical entity: Minoru's self-diagnostic subsystem. |
| **Nexus** | The main menu screen (`menu.lua`). |
| **outline_boost** | Per-theme multiplier for all rough outlines (GC 1.0, Wii 1.4). |
| **Rt:Core** | The Dolphin core family shipped with the project. |
| **Rt:Boost / Prime / Pure / Verbose** | Rt:Core profile families. |
| **Rintromping** | Canonical friendship mantra. |
| **SPDW Factory** | The brand/lab behind DolphinUI. |
| **Suitai Wrist** | Canonical entity: Minoru's wrist hardware. |
| **TENRET** | Canonical entity: Minoru's private packet network. |
| **Tier** | Lite / Std / Max variants of a family profile. |
| **Triptych** | The three-flavour delivery of Rt:Core (Comfort Zone, Bash Arsenal, FrontendONE). |
| **Workshop** | The configuration hub screen and its `workshop/` folder. |
