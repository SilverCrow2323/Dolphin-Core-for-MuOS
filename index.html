🎯 WELCOME TO THE DOLPHIN RT:CORE DATABASE

This dashboard collects community‑tested compatibility reports for the Dolphin Rt:Core on muOS, focusing on GameCube and Wii emulation on H700‑based devices (RG35XX‑H, RG40XX‑H, etc.).

Every test is submitted via GitHub Issues and includes ratings, boot status, playability, FPS ranges, and detailed notes.

🔍 HOW TO USE THIS DASHBOARD

Search & Filters — Use the search bar to find games by title or keywords. Filter by region, boot status, or rating. Sort by title, best rating, FPS, or number of tests.

Game Cards — Each game is shown once, with all available regions displayed as flags. The card shows the best rating and FPS among all regions and tests.

Example card:
Super Mario Sunshine
60 FPS Boots Playable

★ Rating — Overall score (1–5). FPS — Frame rate range. Boots / Playable — Quick status indicators. Flags show available regions.

⭐ THE RATING SYSTEM

  • 5★ – Perfect – Flawless performance, full speed, no issues.
  • 4★ – Great – Very good, minor glitches or occasional slowdowns.
  • 3★ – Playable – Playable with noticeable issues or framedrops.
  • 2★ – Poor – Barely playable, frequent problems.
  • 1★ – Bad – Unplayable or crashes frequently.

Click on any rating panel (1–5★) to filter the list by that score.

🤝 HOW TO CONTRIBUTE

Help grow the database! Submit your own test results via the Send Report button or by opening an issue on GitHub using the dedicated template.
