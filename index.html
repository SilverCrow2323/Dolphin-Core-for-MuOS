⚡ How & About

What is this?

This dashboard is a community-driven compatibility database for Dolphin Rt:Core for muOS — a custom fork of the Dolphin emulator tuned for GameCube and Wii on H700-based handhelds.

Every entry comes from real users who boot a game, play it, and report honestly: which games boot, which crash, which run at 60 FPS and which stutter at 15. Tested on Anbernic RG35XX H, RG40XX H, and RG CubeXX (Allwinner H700, 1 GB RAM).

Each report includes rating (0–5★), boot status, playability, FPS range, Rt:Core version, core profile, and detailed notes about bugs, audio glitches, and tricks that helped.

Compatibility

Inside every game modal, next to the title / region / Game ID, there's a small panel showing the official Dolphin Emulator Wiki compatibility rating — five notches + link to the wiki page.

🌐 Wiki

The notches fill 1→5 based on the wiki's global rating. Ratings are pulled from a local snapshot (Dolphin Wiki API doesn't allow CORS). If a Game ID isn't mapped, it shows "not rated" — the wiki link still works.
