⚡ How & About

What is this?

This dashboard is a community-driven compatibility database for Dolphin Rt:Core for muOS. It collects real test reports from users running GameCube and Wii games on H700-based devices: RG35XX H, RG40XX H, RG CubeXX.

Every report includes rating (0–5★), boot status, playability, FPS range, Rt:Core version, core profile, and detailed notes.
